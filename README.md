# FLOW 운영 관리

제품관리, 고객관리, 출고관리, A/S를 제공하는 한국어 웹앱입니다. 외부 CDN이나 패키지 설치 없이 동작합니다.

## 실행

저장소 루트에서 `python3 -m http.server 8000 --bind 127.0.0.1`을 실행한 뒤 `index.html`을 엽니다.

- 각 메뉴에서 등록·수정·삭제, 검색, CSV 내보내기를 지원합니다.
- 제품의 시리얼번호와 고객코드는 중복 등록할 수 없습니다.
- 등록된 고객과 재고 제품을 선택해 출고합니다. 출고 내역이 있으면 제품 상태는 출고로 표시됩니다. 출고 삭제 시 기존 제품 상태로 돌아갑니다.
- 출고 또는 A/S 이력이 있는 제품, 출고 이력이 있는 고객은 삭제할 수 없습니다.
- A/S는 등록된 제품과 연결됩니다. 완료일 입력 시 완료 상태로 표시합니다.

데이터는 **현재 브라우저의 localStorage에만 저장**됩니다. 서버 데이터베이스, 사용자 인증, 기기 간 공유 및 자동 백업은 구현되지 않았습니다. 브라우저 저장소를 지우면 데이터가 삭제되므로 CSV로 백업하세요. CSV는 내보내기용이며 가져오기 기능은 없습니다. 다중 사용자 운영에는 별도의 서버 및 데이터베이스가 필요합니다.

기존 `movie/`, `todo-list/` 예제는 유지됩니다.
