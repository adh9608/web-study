# FLOW 운영 관리

한국어 제품·고객·출고·A/S 관리 웹앱입니다. GitHub Pages + Supabase 무료 플랜으로 로그인과 공유 PostgreSQL DB를 연결할 수 있습니다.

## 실행

저장소 루트에서 `python3 -m http.server 8000 --bind 127.0.0.1` 실행 후 index.html을 엽니다. npm 설치나 빌드는 필요하지 않습니다.

## 클라우드 설정

[Supabase 연결 안내](supabase/SETUP.md)에 따라 새 프로젝트에서 [DB 설치 SQL](supabase/schema.sql)을 실행하고 직원 계정을 등록한 뒤 config.js에 공개 URL과 publishable key를 입력하세요. 관리자용 비밀 키는 클라이언트에 넣지 않습니다. 설정이 없으면 연결 안내와 기존 브라우저 데이터 보기 버튼이 표시됩니다. 프로젝트 연결 전에는 실제 로그인/DB 공유가 동작하지 않습니다.

## 기능

- 제품·고객·출고·A/S 등록·수정·검색·CSV 내보내기
- 관리자만 삭제 가능, 초대된 직원만 데이터 접근
- 중복 시리얼번호/고객코드/출고 방지, 관련 이력 삭제 제한
- 출고 이력이 있으면 제품 상태를 출고로 표시하고 출고 삭제 시 기존 상태로 복귀
- A/S 완료일 입력 시 완료 표시, 완료일/접수일 검증
- DB 트랜잭션과 버전 검사를 통한 동시 수정 충돌 방지
- 공유 데이터는 새로고침 버튼으로 갱신, 자동 실시간 동기화는 미구현
- 자체 가입·비밀번호 변경·재설정 화면은 미구현, 관리자가 계정 관리

기존 localStorage 데이터는 클라우드로 자동 이전되지 않습니다. CSV는 내보내기용이며 가져오기 기능은 없습니다. 기존 `movie/`, `todo-list/` 예제는 유지됩니다.

## 개발 검증

테스트 도구만 설치하려면 `npm ci`를 실행합니다. `npm test`는 PGlite의 PostgreSQL 엔진에서 실제 스키마·권한·제약조건을 검사합니다. 정적 서버를 8001 포트에서 실행한 뒤 `npm run test:browser`로 브라우저 검증을 실행합니다. Chromium 경로는 기본 `/usr/bin/chromium`이며 `CHROMIUM_PATH`로 바꿀 수 있습니다. 다른 서버 주소는 `TEST_BASE_URL`로 지정합니다.

브라우저 테스트는 실제 SQL 엔진에 연결되지만 Auth/API 전송은 로컬 테스트 대역을 사용합니다. 실제 Supabase 로그인·네트워크·배포 검증을 대신하지 않습니다. 설정 파일도 테스트 대역으로 교체하므로 실제 프로젝트에 테스트 데이터를 쓰지 않습니다.
